# Проверка проекта

Дата: 8 ноября 2026 года.

## Выполнено

- `npm ci` / установка зависимостей: успешно.
- `npm run build`: TypeScript и production-сборка Vite проходят.
- `npm test`: 10 автоматических проверок проходят.
- Контракты запросов сверены по контроллерам, DTO, SecurityConfiguration и сервисам исходного бэкенда, коммит `d4937296795b9b6586a538fc92ef2be92e9b2bac`.

Проверяются запросы входа, различия `phone_number` / `phoneNumber`, Bearer-заголовок, поля `response` / `responses`, создание пользователей, изменение ролей при пустом ответе сервера, удаление с 204, разделение HTTP-ошибок, обработка некорректного ответа, срок действия и восстановление сеанса, соответствие прав ролям.

## Ограничения проверки

- Автоматические проверки API используют подменённый `fetch`.
- Полный запуск Spring Boot с PostgreSQL в этой среде не выполнен: Maven не смог разрешить DNS-имя `repo.maven.apache.org` для загрузки зависимостей. Это не подтверждает ошибку самого бэкенда.
- Визуальная проверка в браузере не выполнена: доступ к браузеру/предпросмотру в среде завершался тайм-аутами, локальный адрес сервера предпросмотра был недоступен.
- Docker-образ не запускался: Docker в среде отсутствует.

Перед защитой следует пройти сценарий демонстрации из README на компьютере с работающим исходным бэкендом. Эти ограничения не скрыты локальными фиктивными данными: приложение действительно обращается к API и показывает ошибку, если сервер недоступен.
